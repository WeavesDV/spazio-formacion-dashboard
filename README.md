# Dashboard de formación — demostración pública

Dashboard de una sola página que explica la clasificación de una base de contactos de una escuela
de masaje: quién hizo qué módulos de la formación y hasta dónde llegó.

**Versión pública de demostración.** Los datos personales (nombre, email, teléfono, localidad y fecha
exacta de última actividad) han sido eliminados de este repositorio. Las cifras agregadas son las reales.

- `index.html` — el dashboard completo, autocontenido: sin dependencias, sin CDN, sin peticiones de red.
- Se abre con doble clic o desde GitHub Pages.

Método: catálogo canónico de cursos (programa · módulo · formato · cohorte) sobre el export del CRM,
más clasificación con un modelo de decisión (Jev / TypeSafe System One).
